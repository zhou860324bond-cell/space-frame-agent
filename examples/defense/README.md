# 教学例题模型

2026-10-10 的真实验收产物；所有长度/力/弹性模量采用 N-m-Pa。

- 复杂例题：[拱形空间网格屋盖](拱形网格屋盖例题.md)：239 节点、622 杆件、18 固定柱脚，含五种基础工况与五种组合、初设超限与拱向截面调整对比；10 张图片为 2026-10-10 版软件的实际整窗截图，界面已在之后改版，数值不受影响。
- 推荐：[双跨空间钢框架例题](双跨空间钢框架例题.md)：12 节点、13 杆件、6 个固定支座，配齐恒载、活载、水平荷载及组合；含直接打开的 JSON、实算参考和五分钟操作步骤。
- 教材对照：[教材图 IV-5](教材图IV-5/导入说明.md)（例 IV-1，三杆原题版与表格建模版）、[教材图 IV-6](教材图IV-6/导入说明.md)（例 IV-2，五杆原题版、表格建模版、考虑/不考虑剪切变形、杆 3 荷载方向试算）。
- 门式刚架.json：24 m 单跨、檐口 7.5 m、屋脊升高 1.2 m、柱脚铰接、Q355；
  恒载 8 kN/m、活载 5 kN/m、风吸 3 kN/m，含三组组合。
  使用软件的离线演示分派调用真实工具生成，不是本轮 AI 识别结果。
- AI悬臂梁.json：本轮实际文字 AI 调用生成的 3 m 悬臂；节点 1 固定、节点 2
  竖向 -1000 N。确定性求解/本地查询最大位移 2.25 mm。
- 圆管节点.json：P219×8 的 L 形两杆节点，梁端竖向 20 kN；用于说明整体梁模型
  与局部实体子模型的关系。预计算实体结果在本机验收目录，JSON 不包含实体结果。

源码启动：在项目根目录使用 .venv/Scripts/python.exe -m desktop.app。
打开 JSON 后必须重新求解；旧结果不会随模型加载。
各 JSON 里记录的 `results\…` 路径是当时本机的输出目录（已被 .gitignore 忽略），仓库里没有这些文件。
