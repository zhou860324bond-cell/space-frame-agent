# 拱形空间网格屋盖：初设与截面调整

参考用户提供的拱形屋盖图片外形，建立单层柱面三角网格屋盖。
原图没有尺寸和截面标注，以下参数均为明确的教学演示假设，不是图纸识别或尺寸测量结果。

直接打开 [调整版模型](拱形网格屋盖.json)，也可打开 [初设模型](拱形网格屋盖_初设.json) 展示超限定位与截面修改。

## 几何与截面

| 项目 | 参数 |
|---|---|
| 跨度 / 长度 | X 方向 24 m / Y 方向 36 m |
| 檐高 / 起拱 / 顶高 | 6 m / 5 m / 11 m |
| 拱形 | 圆弧离散，半径 16.9 m，沿拱向等角度分 12 段 |
| 纵向划分 | 16 段，每段 2.25 m |
| 屋面网格 | 221 个节点，拱向、纵向及交替斜向杆件连接成三角网格 |
| 柱与支座 | 两侧每隔 4.5 m 设柱，共 18 根 6 m 柱，柱脚全部固定 |
| 总规模 | 239 个节点、622 根空间梁杆件、18 个固定柱脚 |
| 材料 | Q355，E = 206 GPa，ν = 0.3，密度 7850 kg/m³ |
| 允许拉、压应力 | 305 MPa，教学设定 |
| 拱向杆组 | 初设 P219×8；调整版 P273×10 |
| 纵向杆组 / 斜向杆组 / 柱 | P168×6 / P159×6 / P406×16 |

管径与壁厚以 mm 表示。模型计算单位为 N-m-Pa，Z 轴向上。
所有杆端按刚接处理，斜杆与网格角点相连；不增加没有实际接头的相交节点。
采用线弹性三维梁模型，视口圆杆表达分析中心线，不表达管壁实体。

## 荷载与组合

屋面荷载按水平投影面积 24×36 = 864 m² 分配到各网格角点，边、角节点按相邻网格面积分担。
杆件自重用各截面面积、实际杆长、密度与 g = 9.81 m/s² 计算，等效分配到杆端；截面调整后重新计算自重。

| 基础工况 | 题设 |
|---|---|
| DL | 杆件自重 + 屋面 0.60 kN/m²，全局 −Z 方向 |
| LL | 全屋面 0.40 kN/m²，全局 −Z 方向 |
| WX | 全屋面等效水平荷载 0.25 kN/m²，全局 +X 方向 |
| WU | 全屋面等效风吸 0.50 kN/m²，全局 +Z 方向 |
| ASYM | X < 12 m 的半跨屋面 0.40 kN/m²，全局 −Z 方向 |

组合：ULS-G = 1.3 DL + 1.5 LL；ULS-GW = 1.3 DL + 1.5 LL + 1.5 WX；
ULS-UP = 0.9 DL + 1.5 WU + 1.5 WX；ULS-ASYM = 1.3 DL + 1.5 ASYM + 1.5 WX；SLS = DL + LL。
这些系数和等效风荷载用于功能演示，没有依据场地参数进行规范风荷载设计。

## 实际求解对比

两个模型均经过真实模型校验、求解和十组工况/组合的外力及力矩平衡独立核对。
原始查询摘录及截图哈希见 [实算参考](拱形网格屋盖参考结果.json)。

| 查询 | 初设 | 调整版 |
|---|---:|---:|
| 杆件自重 (kN) | 593.092445 | 696.413543 |
| ULS-GW 最大节点平移合量 (mm) | 143.156560 | 99.216702 |
| SLS 最大节点平移合量 (mm) | 102.210266 | 70.983693 |
| 全部工况及组合的最大应力比 | 1.0116 | 0.8059 |
| 当前工具验算结论 | 杆件 73、97、121 强度超限 | 当前验算项通过 |

ULS-GW 最大位移均在节点 110，坐标约为 (9.782424, 18, 10.853876) m。
截面调整按整个拱向杆组统一进行，未修改荷载系数、允许应力或支座以取得通过结果。
调整版较重，因此它是可展示的改进方案，不代表已经完成重量最优设计。
当前结论针对本软件的线弹性梁模型与验算项，未包含网壳整体非线性稳定、初始缺陷和节点连接设计。

## 五分钟演示

1. 打开调整版 JSON，等轴测观察拱形和三角网格，再切正视、俯视，说明几何与 18 个固定柱脚。
2. 查看四种截面和五种基础工况，点击校验、求解；模型文件不携带旧求解结果，打开后重新求解。
3. 选择 ULS-GW，查看变形、轴力云图、弯矩云图和梁截面正应力云图。变形按界面标注的系数放大。
4. 选择 ULS-ASYM，展示半跨加载导致的不对称响应，查看真实查询位移；云图读数以当前字段、单位和图例为准。
5. 打开初设模型并求解，展示三根杆件超限，再用两版截图说明拱向截面从 P219×8 调为 P273×10 后的变化。

## 复现

在项目根目录使用虚拟环境执行：

```powershell
$env:PYTHONUTF8 = '1'
.venv/Scripts/python.exe examples/defense/生成拱形网格屋盖.py
.venv/Scripts/python.exe examples/defense/生成拱形网格屋盖.py --strengthened --output results/defense_vault_strengthened
.venv/Scripts/python.exe examples/defense/截图拱形网格屋盖.py --output results/defense_vault_screenshots
```

前两条生成并计算初设与调整版，完整工具返回值保存在各输出目录；第三条在 Windows 原生软件窗口中打开当前例题文件、重新求解并截图。
