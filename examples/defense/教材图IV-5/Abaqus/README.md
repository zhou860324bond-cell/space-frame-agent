# 图 IV-5：Abaqus 整体梁与节点3局部实体

本例以原题三杆 JSON 为输入，已在本机 Abaqus/Standard 6.14-1 实际完成整体求解和三档局部实体求解。脚本兼容 Abaqus Python 2.7；不修改原 JSON，不依赖本项目虚拟环境。它是针对图 IV-5 的算例，不是任意 JSON 的通用实体转换器。

## 打开已求解文件

1. 将交付压缩包解压到纯英文目录，例如 `C:\IV5_Abaqus`。Abaqus 6.14 对中文目录的兼容性有限。
2. 在 Abaqus/CAE 中打开 `IV5_global_and_node3.cae`。模型列表包含整体 `Global_B33` 和节点3的 `Node3_C3D10_h20`、`Node3_C3D10_h15`、`Node3_C3D10_h10`；可以检查几何、网格、材料、耦合、边界和荷载。
3. 切到 Visualization 模块，通过 File → Open 打开 `local_h10.odb`。选择最后一个 `LOCAL` 帧，显示 `S → Mises` 应力云图；局部模型的应力单位是 **MPa**，位移单位是 **mm**。
4. 整体结果打开 `global_b33.odb`。整体单位是 **N-m-Pa**，`U1/U2/U3` 以 **m** 表示，乘1000后才是mm；节点3、4保留原编号。
5. 文件夹包含已求解的三档 ODB、原始 INP、真实 Abaqus PNG、JSON结果及作业状态和诊断日志。CAE用来编辑模型，ODB用来查看已有结果。

需要重新计算时双击 `run_case.bat`；若命令未找到，从开始菜单打开 Abaqus Command 后执行该批处理。会依次重新生成整体输入、求解整体、提取切口受力、建立局部实体、求解三档网格并输出结果。重新运行会更新同名算例产物。

## 整体模型与荷载

- 原题4个节点、3根物理杆件、节点1和2固接，实心圆D100，E=210GPa，ν=0.3。
- 本例整体为 **B33 Euler–Bernoulli 梁**，不考虑横向剪切变形。不是B31。
- 横杆从节点3起前3m作用全局−Z均布800N/m，中点作用全局+X集中力4000N；节点3的全局+Y力2000N、节点4的全局−Z力1000N及绕−X力矩3000N·m全部保留。
- 分析网格在均布边界、中点集中力和两处局部切口位置增加节点，共7个分析节点、6个B33单元；物理模型仍是三根杆件。分析细分不会增加支座或改变刚接条件。
- 均布合力为 `800×3=2400 N`，距节点3为1.5m。全部外力为 `[4000,2000,-3400] N`，实际整体支座合力为 `[-4000,-2000,3400] N`。

实际Abaqus与当前自研求解器对照（均为原题EB条件）：

| 节点 | Abaqus Ux/mm | 自研 Ux/mm | Abaqus Uy/mm | Abaqus Uz/mm |
|---:|---:|---:|---:|---:|
| 3 | 14.394388534 | 14.394388430 | −2.382437000 | −0.002398722 |
| 4 | 10.238504037 | 10.238504110 | −2.391212387 | 7.826641202 |

两节点三个位移分量的最大绝对差约 `1.16×10^-7 mm`，此精度仅描述本例与ODB输出舍入；不代表通用工程精度。截面按照 `A=πR²`、`Iy=Iz=πR⁴/4`、`J=2I` 定义。

## 局部实体的受力传递

选节点3，连接杆件1和2，两根实心圆杆从该节点分别沿+Y和−Z截取200mm。局部原点对应整体 `(0,0,3)m`。几何为两根相交圆柱的连续并集，未假定焊缝、圆角、连接板或真实制造细节。

使用三维线弹性 **C3D10** 实体；它包含完整三维变形及剪应变，不能将整体梁“不考虑剪切”的假设误读为实体单元也取消剪应变。

1. 在Abaqus整体梁的真实切口节点提取NFORC、U和UR。受均布荷载的外段需把它的一致节点荷载计入NFORC，才得到施加到局部模型的真实切口力和力矩；不能直接把节点中心的杆端力搬到200mm外的切口。
2. 杆件2切口用运动耦合约束截面，参考点位移及转角取整体Abaqus结果；杆件1切口用运动耦合传递整体切口的三力、三力矩。
3. 节点3的2000N集中力由节点中心参考点，通过分布耦合施加到暴露的 `y=0,z>0` 半圆端面。合力及关于节点的零力矩被保留。**这一有限加载区是明确的建模假设**：原JSON未给加载头几何，换用连接板或不同加载区会改变局部应力。
4. 局部横杆前200mm内的均布荷载保留：用 `q/A` 体力在原横杆圆柱域内施加。积分合力为−160N，形心在+Y 100mm；不是把整体的全部2400N再施加到局部。
5. 两切口、节点直接荷载和局部体力的六分量平衡已检查；实体支承反力和反力矩与整体对应切口吻合。精细网格最大反力分量差约0.0042N，最大反力矩分量差约1.52N·mm。

## 文件与复算

- `model.json`：与原题JSON字节一致的输入。
- `prepare_case.py`：编译整体B33输入及分析节点映射。
- `extract_global.py`：由Abaqus ODB读取位移、反力、切口原始内力及修正后的切口外力。
- `build_local.py`：建立可编辑局部实体CAE并写三档INP。
- `post_results.py`：读取局部积分点应力、反力、质量警告及真实云图。
- `run_case.py` / `run_case.bat`：完整复算入口。
- `reference_results.json`：2026-10-12本机实算参考，含输入指纹、整体对照与局部三档结果。
- `config.json`（交付包内）：局部截取长度与三档网格种子。该算例限定节点3和原题几何；改截取长度后必须重新执行整体计算来提取新切口数据。200mm只是初始范围，不是原题杆长。

方法依据：Abaqus官方文档的 [B33梁假设](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEELMRefMap/simaelm-c-beamelem.htm)、[耦合约束](https://docs.software.vt.edu/abaqusv2025/English/SIMACAECSTRefMap/simacst-c-coupling.htm)、[NFORC输出](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEOUTRefMap/simaout-c-std-wholeelementvariables.htm)、[体力接口](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEKERRefMap/simaker-c-bodyforcepyc.htm)。文档链接用于方法说明，实际脚本接口已用6.14验证。
