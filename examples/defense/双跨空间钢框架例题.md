# 例题：双跨单层空间钢框架

适合五分钟答辩：展示空间建模、荷载组合、有限元求解、结果显示和计算书导出。
直接打开同目录的 [双跨空间钢框架.json](双跨空间钢框架.json)，无需手工补支座。

## 题目

一座单层空间钢框架沿 X 方向设置两个 6 m 跨，沿 Y 方向宽 4 m，高度为 3.6 m。
六根柱和七根屋面梁均为刚接，六个柱脚全部固定，Z 轴向上。
采用线弹性空间梁模型，不计楼板、连接局部变形和二阶效应；静力荷载不额外叠加杆件自重。

| 参数 | 题设 |
|---|---|
| 材料 | Q355，E = 206 GPa，ν = 0.3，密度 7850 kg/m³ |
| 柱截面 | H350×350×12×19 mm |
| 梁截面 | H350×175×7×11 mm |
| 允许拉、压应力 | 均为 305 MPa，教学演示设定 |
| 固定支座 | 底部节点 1～6，平移及转动共六个自由度全部约束 |
| 基础工况 DL | 全部七根屋面梁施加全局 −Z 方向均布荷载 5 kN/m |
| 基础工况 LL | 全部七根屋面梁施加全局 −Z 方向均布荷载 3 kN/m |
| 基础工况 WX | 六个屋面节点分别施加全局 +X 方向水平力 2 kN |

组合：ULS-G = 1.3 DL + 1.5 LL；ULS-GW = 1.3 DL + 1.5 LL + 1.5 WX；SLS = DL + LL。
组合系数及允许应力用于演示，不作为项目的规范设计结论。模态质量仅来自杆件材料密度，不含楼面附加质量。
JSON 使用 N、m、Pa；截面名称中的数字使用 mm。

要求校验模型、求解各工况和组合，观察水平侧移与梁内挠度，核对支座总反力，查看杆件应力比并导出计算书。

## 五分钟演示操作

1. **0:00～0:40**：通过软件的打开入口载入 JSON。说明 12 个节点、13 根杆件、6 个固定支座；切换等轴测并适应窗口。
2. **0:40～1:30**：查看材料、截面、支座及三种荷载工况，强调这些是可检查的模型参数。点击校验，再点击求解。
3. **1:30～2:40**：选择 ULS-GW，查看变形、云图和内力图。说明变形有显示放大系数，实际节点位移为毫米量级；云图字段以图例为准。
4. **2:40～3:40**：查询最大节点位移；再选择 SLS 查询梁内最大挠度。指出节点位移与梁内部挠度属于不同查询，不能直接互换。
5. **3:40～4:30**：查看支座反力与应力比，说明 ULS-GW 的竖向总反力为 396 kN，水平总反力为 −18 kN，和外荷载平衡。
6. **4:30～5:00**：导出计算书，展示模型、反力、内力和结果图。总结数值来自本地求解器，输入与结果均能追溯。

可提前收起命令区和抽屉，保留主要视口。打开模型后需要重新求解，模型文件不携带旧求解结果。
现场直接使用本例求解；这个 H 型钢梁模型用于整体框架演示，圆管节点实体分析使用已有的独立圆管例题。

## 重新生成

在项目根目录执行：

```powershell
$env:PYTHONUTF8 = '1'
.venv/Scripts/python.exe examples/defense/生成空间框架例题.py
```

输出模型、原始工具结果以及 Markdown/Word 计算书到 results/defense_space_frame。
默认计算书展示 ULS-GW，强度检查取全部工况及组合。
