# FrameLab 使用说明

## 启动

1. 将压缩包完整解压到本地可写目录，再双击 FrameLab.exe。
2. 请保留整个文件夹及其中的 _internal 目录，不要单独移动程序文件。
3. 首次启动可能需要稍候；请勿在压缩软件内直接运行。

## 基本使用

建模、求解、结果查看和报告导出可在本地离线使用。
建议先保存工程，再进行计算；查看结果时请核对工况、单位和边界条件。

## AI 功能（可选）

在“模型连接设置”中配置自己的服务地址、模型和 API 密钥，再检测连接。
AI 对话与图纸识别需要联网及相应服务权限；未配置时仍可使用本地计算功能。
使用 AI 时，对话及相关工程上下文会发送至所选服务，费用由该服务按账户计收。

## 常见问题

- 提示缺少文件：重新完整解压，确认 _internal 与 FrameLab.exe 在同一目录。
- 提示缺少运行库：根据系统提示安装微软官方的 x64 Visual C++ 运行库。
- 三维视图空白：更新显卡驱动后重启程序。
- 无法启动：查看系统安全软件的拦截记录，并保留错误信息供排查。
- AI 连接失败：检查网络、服务地址、模型名称与密钥状态，再检测连接。

## 许可

第三方组件的许可文件保留在随包依赖目录中，请在再次分发时一并保留。
