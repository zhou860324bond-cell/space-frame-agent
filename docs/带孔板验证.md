# 带孔板应力集中 —— 自研 C3D10 链路对着教科书答案的验证

> 本文件由 `tools/verify_plate_with_hole.py` 生成，不要手改。

板 240×100×10 mm，中心圆孔 d=20 mm（d/W=0.2），一端全约束、另一端施加 100 MPa 的毛截面名义拉应力。

参照值：Heywood 经验式 `Kt = 2 + (1−d/W)³` = **2.512**（以净截面名义应力为分母，d/W<0.9 时约 2% 精度）。

**为什么比 Heywood 大约 4%**：Kt=3 那一套是**薄板平面应力**的结论，而本例 t/d = 0.5，厚度不可忽略。孔边应力沿板厚不是常数——中面附近受周围材料约束更强，比自由表面高几个百分点。最细一档网格的实测分布：

| 板厚位置 z (mm) | 孔边 σxx (MPa) | 局部 Kt |
|---:|---:|---:|
| 1.00 | 319.1 | 2.553 |
| 3.00 | 327.2 | 2.618 |
| 5.00 | 327.5 | 2.620 |
| 7.00 | 326.4 | 2.611 |
| 9.00 | 314.6 | 2.517 |

中面（z≈5）最高、自由表面（z=0 与 z=10）最低，与三维解的已知性质一致。**这不是一句「大概是三维效应」，是一条能自己量出来的曲线。**

净截面名义应力 125.0 MPa。峰值位置 [120.1, 60.0, 4.4]，即孔边 90° 处（y=60 或 40）——与理论一致。

收敛判据（`solid_joint.diagnose_peak_convergence`）：**converging**。

这一条与相贯线那个算例是一对：相贯线不带倒圆时是**应力奇异点**，
峰值随网格加密无上界，判据报 `diverging`；带孔板的峰值是有限的，
判据报 `converging`。**两个方向都试过，判据才算验过。**
