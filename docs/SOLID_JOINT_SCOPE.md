# 节点局部实体子模型：能力边界

整体结构继续用空间梁内核算，选中某个节点后把相连杆件截成短臂、拼成 C3D10
实体在 Abaqus/Standard 里重算一遍，用来观察杆件相交处的应力集中。切割面通过
参考点传入梁模型的六分量截面力。

入口：agent 工具 `analyze_joint_solid`；`dry_run=true` 只建规格，不需要本机装
Abaqus。

## 这个模型给什么、不给什么

**几何里没有焊缝，也没有倒圆。** 两根管子直接布尔合并，相贯线是一条尖锐的
凹角。在线弹性里这是一个**真正的应力奇异点**：

$$\sigma_{\text{peak}} \sim h^{-\lambda},\qquad \lambda > 0$$

网格越细峰值越高，不收敛到任何有限值。由此推出三条硬性口径：

| 量 | 用途 | 能不能写进结论 |
|---|---|---|
| `max_abs_principal_mpa` | 观察应力分布形态 | **不能**。它是网格密度的函数，不是结构的性质 |
| `p99_abs_principal_mpa` | 同上，抗噪一些 | **不能**。P99 只是缓解奇异，不消除它 |
| `hot_spot_extrapolation[*].hot_spot_mpa` | 热点应力 | **可以**。IIW 0.4t/1.0t 线性外推，网格不敏感 |
| `stress_concentration_factor` | 应力集中系数 | 拿得到外推值才给，否则**明确拒绝并说明理由** |

热点应力外推取焊趾外 0.4t 与 1.0t 两处的表面应力，线性外推回焊趾：

$$\sigma_{hs} = \tfrac{5}{3}\,\sigma(0.4t) - \tfrac{2}{3}\,\sigma(1.0t)$$

两个取样点都在奇异影响区之外，这正是它被写进规范的原因。焊趾位置不靠几何
API 求，而是数值确定：某根臂的表面节点若同时落在另一根臂的圆柱内，说明它还在
相贯区内，取这些节点里轴向坐标最大的那个即为焊趾。

## 收敛判据为什么要三档网格

旧判据只比较最后两档，变化小于 5% 即报"已收敛"。但在奇异点上，**任意相邻两档
的变化都可以很小**，只要网格没细到位——于是奇异问题会被判成收敛，然后拿一个
纯属虚构的 Kt 去写报告。

三档以上才分得开：真收敛时逐次变化会逐档缩小；发散时逐次变化不缩小甚至变大，
且峰值随加密单调上升。同时用 $\log\sigma \sim \text{slope}\cdot\log h$ 拟合斜率，
slope 明显为负即奇异特征。判定结果写在 `peak_convergence.verdict`：
`converging` / `diverging` / `inconclusive`。

## 明确拒绝的情况

不做几何猜测，缺条件就报错，不给一个"精确但不是用户结构"的答案：

- **非圆截面。** 工字形节点需要板件、焊缝、加劲肋和倒圆参数，缺这些就自动拼实体
  没有意义。
- **多种材料。** 布尔合并后是一个实体，各臂材料不同就无法赋一套截面属性。
- **带刚域偏移的杆端。** 杆端力的作用点与几何端点不重合，映射不过去。
- **相连杆件少于两根。** 不构成节点。
- **杆件太短**，节点外留不出不受切割边界干扰的短臂（要求 ≥ 1.5D）。
- **实心圆截面拿不到热点应力**：没有壁厚 t 就没有 0.4t/1.0t，此时如实报 None，
  不拿半径凑一个"看起来像 t"的数。

## 会被记为警告、但不阻断的情况

- 节点上直接挂有集中力。整体杆端力仍包含它的传递效应，但实体模型不知道力在
  节点域里怎么扩散（没建加载头几何）。
- 非锚固臂名义正应力接近零，此时 Kt 没有有意义的分母。

## 验证到什么程度

`tests/test_solid_joint.py`（30 项）覆盖**不需要 Abaqus 的那一半**，也就是全部
数值语义所在：

- 由 A 与 I 反演圆管外径内径可原样还原
- 名义正应力等于闭式解 $M c / I$（L 形节点算例，逐位相同）
- 柱臂比梁臂多出的正应力正好是 $P/A$
- 切割面力的符号是"外部结构作用于子模型"，与杆端力相反
- 热点外推能从已知直线还原截距，且**不受焊趾附近尖峰影响**
- 收敛判据能把幂律发散判成 `diverging`、把二阶收敛判成 `converging`
- 全部拒绝路径
- 生成的 Abaqus 脚本能被解析，且 `%%` 占位符已展开

**没有验证的部分**：Abaqus 脚本的实际执行。它需要本机 Abaqus 6.14，CI 里跑不了。
表面取样那段尤其未经实跑，因此在脚本里包了异常兜底——取样失败会写
`surface_samples_error` 并继续，不会让已经解完的作业作废。

第一次在装有 Abaqus 的机器上跑之前，这个模块的实体分析结果**不应写进报告**；
`dry_run` 那一段则已经可以引用。
