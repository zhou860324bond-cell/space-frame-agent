# 工程视图验收基线

本清单用于防止“求解数值正确，但符号、方向或结果名称误导用户”。自动验收位于
`tests/test_engineering_visual_acceptance.py`，每项都同时检查计算结果和显示语义。

| 算例 | 数值基线 | 视图与符号基线 |
|---|---|---|
| 8 m 简支梁，25 kN/m 向下均布荷载 | 跨中 `|Mz| = wL²/8 = 200 kN·m`，两端为零 | 标签为 `wz=-25 kN/m [global]`；两个支座逐项列出约束 DOF |
| 6 m 悬臂梁，端部 50 kN 向下集中力 | 根部 `|Mz| = PL = 300 kN·m`；整体平衡通过 | 标签为 `Fz=-50 kN [global]`；力用直箭头，力矩/转角必须用右手圆弧箭头 |
| 门式刚架，梁上均布荷载并受水平力 | 整体六分量平衡通过 | 自动采用 XZ 正投影；水平力为 `Fx=+15 kN`，竖向线荷载为 `wz=-20 kN/m` |
| 两跨一开间两层空间刚架 | 整体六分量平衡通过；局部方向余弦阵正交且行列式为 +1 | 自动采用等轴测；选中杆件显示与求解器完全同源的 local x/y/z；有符号云图声明采用杆件局部轴 |

人工检查时还应确认：红/绿/蓝局部轴分别表示 x/y/z；圆弧箭头旋向符合右手定则；
沿杆内力图的正值在零线上方、负值在零线下方，过零点、极值和集中力跳跃点可见；
结果视口标题明确写明 `BEAM CENTERLINE INTERNAL-FORCE RESULT`，不得将其描述为实体截面应力云图。

## 结果核查闭环

- 在变形或梁内力云图模式选择杆件时，点击位置必须投影到中心线并返回距 i 端位置、
  六个局部内力分量、全局/局部位移和可用的极端纤维正应力。
- “定位当前分量极值”必须同时给出杆件、距 i 端位置、带符号数值和视口标记。
- 截面正应力图仅表示 `N + My + Mz` 的线性正应力，受拉为正；不含剪力与扭转
  剪应力。截面缺少 `cy/cz` 时必须明确拒绝，不允许估算。
- 梁内力云图支持 95% 裁剪/满量程、正负筛选、变形叠加与极值标签开关；这些
  选项只能改变显示副本，不得修改 Result DB 或求解数组。
- 支座和荷载可从选中对象的边界条件面板修改、复制或删除。任何实际修改后，
  后端解、Result DB、探针缓存和桌面“已求解”状态必须同步失效，并提示重新求解。
