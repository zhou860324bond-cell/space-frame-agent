## §3-9 八条逐条核对（重点）

| # | 讲义内容 | 状态 | 实现 / 缺什么 |
|---|---|---|---|
| 一 | **计算自重和截面积** `G = ρ·A·l·g` | ✅ | agent 工具 `add_self_weight`，按 ρ·A·g 生成均布荷载 |
| 二 | **求支座反力** | ✅ | 结果含 RF/RM；整体平衡校核有金标准 |
| 三 | **强度验算**：逐杆内力与应力、\|σ\| 对比许用应力（**拉压许用不同**）、**屈曲失稳校核** `Pcr = π²EI/(μl)²`，μ=1/2/0.7/0.5 | ⚠️ **部分** | 有 `stress.py` 算极端纤维正应力（`N/A ± M·c/I`，已按 `M·c/I` 验证到 1.7e-16）；`section_optimizer` 内部用到 `max_stress` 约束。**但没有面向用户的强度验算工具**：没有逐杆应力比输出、没有拉压区分许用应力、**没有逐杆欧拉校核，源码中不存在计算长度系数 μ、长细比、回转半径** |
| 四 | **对称性的利用**（半结构、半杆件、半节点荷载） | ❌ | 无 |
| 五 | **装配内力问题** `P = Δl·EA/l` | ❌ | 无初应变／装配误差荷载 |
| 六 | **温度应力问题** `Δl = α·ΔT·l`，转化为装配内力 | ❌ | 无。材料定义里也没有线膨胀系数 α |
| 七 | **支座沉陷问题**（转化为装配内力） | ✅ | agent 工具 `set_prescribed_displacement` |
| 八 | **节点编号**：先固定后可动；左右节点号差值尽量小以减小带宽 `ibdw = max[2(j−i)+1]` | ❌ | 无带宽计算，无编号优化 |

**关于第三条要特别注意**：项目有 `buckling_analysis`，做的是**整体特征值屈曲**
`(K + λK_g)φ = 0`——理论上比欧拉公式高一档。但讲义要的是**逐杆的欧拉校核**，
两者不是一回事。老师如果问「强度验算里屈曲怎么校核的，计算长度系数怎么取」，
现在答不上来。**有更高级的方法不等于覆盖了讲授内容。**

## 缺口清单与建议

按**答辩风险**排序，不是按工作量。

### 1. 强度验算（§3-9 三）——风险最高

题目里「灵活应用」的第三条，老师最容易照着讲义直接问。

要补：

- 逐杆应力比工具：`σ_max / [σ]`，**拉压分别给许用值**
- 逐杆欧拉校核：`Pcr = π²EI/(μl)²`，μ 按两端约束取 1 / 2 / 0.7 / 0.5，输出 `N/Pcr`
- 材料加「许用拉应力／许用压应力」，杆件加「计算长度系数 μy / μz」

工作量：约一天。`stress.py` 已经能给极端纤维应力，主要是接口和数据字段。

### 2. 装配内力 + 温度应力（§3-9 五、六）——性价比最高

**这两条是同一个机制**：都归结为「给杆件一个初始长度变化 Δl，转成沿杆轴的
等效节点力 `P = EA·Δl/l`」。装配是直接给 Δl，温度是 `Δl = α·ΔT·l`。

工作量：合起来约半天到一天。材料加一个 α 字段即可。

### 3. 带宽优化编号 + 等带宽带状存储 + 总刚一维存储（§3-9 八、§3-10、§4-6）

**这是两整节课的内容，缺了很显眼。**

现状是 SciPy 稀疏 LU——工程上比带状存储更好，但这不能替代「实现了讲授内容」。

建议做成**教学对照路径**而不是替换：实现带宽最小化编号 + 一维变带宽存储 +
配套求解，然后**与稀疏解逐位对比**，证明两者数值一致，再给出规模—耗时—内存
的对比曲线。

这样一举三得：补上了讲授内容、证明了自己理解了为什么现代求解器换了方案、
报告里多一节有数据的对比。**这一条如果做，是全部缺口里最能加分的。**

工作量：一到两天。

### 4. 对称性的利用（§3-9 四）——可以论证不做

现代做法通常直接算全模型，对称性主要是手算时代节省工作量的手段。

但**必须在报告里明确写出来「为什么不做」**，不能装作讲义里没有这一条。
如果时间允许，做一个「对称性检测 + 提示」也够交代——检测出结构对称就告诉
用户「本结构关于 X 平面对称，可用半结构校核」。
