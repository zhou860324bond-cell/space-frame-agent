# 一分钟实机演示与五分钟彩排

适用：中期汇报含实机演示 v5。总时长 **5分钟**，其中实机操作 **1分钟**。
采用同一拱形空间网格屋盖，衔接“方案对比”与“局部扩展”页面。

## 全场排时

| 全场时间 | 页面与重点 |
|---|---|
| 0:00–0:10 | 第1页：项目与汇报内容 |
| 0:10–0:35 | 第2页：工程输入问题、方法和价值 |
| 0:35–1:20 | 第3页：运行时Agent、有限元内核、开发中人机协作 |
| 1:20–1:40 | 第4页：实现模块及有出处的规模指标 |
| 1:40–2:05 | 第5页：同一屋盖截面调整的响应与自重代价 |
| 2:05–3:05 | 第6页：切换软件，实机求解与节点位移查询 |
| 3:05–3:25 | 第7页：局部实体扩展及验证范围 |
| 3:25–4:00 | 第8页：缺失荷载被补零的问题及修复 |
| 4:00–4:45 | 第9页：现阶段总结与对应评价方法的研究计划 |
| 4:45–5:00 | 翻页、窗口切换及结束缓冲 |

第10、11页为隐藏备答，不计入正常放映。完整口头稿在各页备注中，来源和详细论证不用逐句朗读。

## 会前准备

1. 使用已验收的源码环境打开软件。当前项目入口为根目录的 `run_desktop.bat`，首次启动与依赖准备应提前完成。
2. 打开[调整版屋盖模型](../../examples/defense/拱形网格屋盖.json)，不要打开初设文件。确认239节点、622根杆件、18个固定柱脚。
3. 提前点击「3 校验」并按F5试算一次，确认能选择 `ULS-GW`、点击「变形」和查询节点110；随后返回「模型」视图供现场开始。现场仍按F5重新计算。
4. 收起顶部命令与左右、底部抽屉，设置等轴测视角和「适应窗口」（F）。窗口建议1920×1080；在实际投影分辨率下检查模型、工况栏和结果表是否可读。
5. 把软件与PowerPoint准备在可切换的位置。先在放映中试一次Alt+Tab，确认投影能显示软件；回到放映第6页后，按右方向键进入第7页。
6. 结果表可提前拖动面板边缘调整高度，或用标题栏右侧图标移出为独立窗口。读取「位移幅值」时可以向下滚动，不能只看左侧属性的X/Y/Z坐标。

## 现场一分钟

| 演示内时间 | 实际操作 | 配合讲述 |
|---|---|---|
| 0–10秒 | 从第6页切换到软件，轻微旋转调整版模型 | “这是同一屋盖，239节点、622根杆件，18个固定柱脚。” |
| 10–25秒 | 单击视口移出输入焦点，按F5，等待「求解完成」 | “现场由确定性数值程序求解，包含5个基础工况和5个组合。” |
| 25–40秒 | 工况下拉框选择 `ULS-GW`，点击「变形」 | “当前为ULS-GW组合，显示变形按界面系数放大。” |
| 40–55秒 | 点击「模型树」，输入 `节点 110`，按Enter；查看自动打开的结果表，必要时向下滚动 | “节点110的Ux约25.1003mm、Uz约−95.9892mm，平移幅值99.2167mm。表格读取实际求解值，未放大。” |
| 55–60秒 | Alt+Tab返回PowerPoint，按右方向键到第7页 | “这个读数与前面的方案对比一致。下面说明局部实体的验证范围。” |

本段展示确定性计算和可追溯查询。运行时AI负责意图理解、草稿及工具组织，人工审核见第3、8页。
实机只执行这一条主线，其他工况、实体计算和报告导出可在提问环节展开。

## 核对结果与条件

- 模型为 `拱形网格屋盖.json`，拱向截面 **P273×10**。初设P219×8的结果为143.156560mm，不能用来核对调整版。
- `ULS-GW = 1.3 DL + 1.5 LL + 1.5 WX`。节点110的Ux=25.100262mm、Uy约0、Uz=−95.989222mm，平移幅值99.216702mm。后三个转角分量单位为rad。
- 节点110的原始坐标约为(9.782424, 18, 10.853876)m，属于建模坐标；位移来自结果表，单位mm。
- 「位移幅值」为平移向量长度，不是Ux单分量。换工况后读数会改变，也不能把另一工况在其他节点的最大值当作节点110结果。
- 2026-10-11已用真实MainWindow、F5后台求解和模型树Enter定位复现。该次求解及界面刷新约7.984秒，仅为本机这次操作的记录，现场用15秒时间窗等待。
- 尺寸、截面和等效荷载属于教学演示假设；结果限定于当前线弹性梁模型，不能据此宣称重量最优或完整工程安全认证。

参考模型及原始对比见[屋盖例题](../../examples/defense/拱形网格屋盖例题.md)、[实算参考](../../examples/defense/拱形网格屋盖参考结果.json)。
本轮操作与节点自由度记录保存在本机 `results/ppt_revision_v5/preflight/实机复现.json`，PPT第6页已嵌入实际软件截图。

## 超时后的接续

累计约45秒仍未完成查询时，返回第6页，用剩余15秒讲真实截图中的读数，再按右方向键进入第7页。
准确表述为：“这张截图记录同一模型的真实计算结果，节点110位移幅值为99.2167mm。”
只有现场实际完成求解并读取结果时，才说“刚才现场求解得到”。
