用讲义的一维变带宽 LDLᵀ 把同一个方程组再解一遍，与默认的稀疏 LU 相比最大相对偏差 **5.3e-16**（一致）。两条路径共用同一份装配、约束消元与反力回算，只有分解这一步不同，所以这个差值只反映解法本身。
