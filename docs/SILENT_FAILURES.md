# 静默失败目录（Silent Failures）

> 工程仿真里最危险的不是报错，而是**作业正常结束、数值看起来合理、但模型本身有问题**。
>
> 本文档记录空间刚架求解中 8 类常见的静默失败，每类给出原理、真实案例、检测方法和修复建议。
> 对应的自动检测代码在 `src/silent_failures.py`，求解后调用 `detect_silent_failures(model, sol)` 即可自动扫描。

---

## 检测项总览

| # | ID | 严重度 | 检测内容 |
|---|---|---|---|
| 1 | `insufficient_supports` | critical | 支座约束不足以限制刚体运动 |
| 2 | `excessive_displacement` | critical | 位移超过结构尺寸的 10% |
| 3 | `zero_reaction_with_load` | critical | 有外载荷但支座反力为零 |
| 4 | `zero_internal_force` | critical | 有外载荷但杆件内力为零 |
| 5 | `near_singular_stiffness` | critical | 刚度矩阵条件数过大 |
| 6 | `reaction_load_balance` | critical | 反力合力与外载荷合力不平衡 |
| 7 | `load_magnitude_anomaly` | warning | 载荷量级与材料不匹配 |
| 8 | `section_orientation` | warning | 弱轴惯性矩大于强轴 |
| 9 | `no_applied_load` | critical | **一个荷载都没有却照样求出一套全零结果** |

> 第 9 项是 2026-09-16 补的，补的是第 3、4 项的**盲区**：那两条的前提都是
> "有外载荷"，没有载荷时它们直接跳过。于是最基本的一种静默失败反而没人管——
> 求解返回成功，弯矩内力全零，界面上看不出异常。触发路径至少两条：
> `set_load_cases` 因杆件号写错而失败（它会如实报错并保持原模型不变）但调用方
> 没看返回值；或者建了工况却没往里放荷载（空工况是被接受的）。
>
> **2026-09-16 晚：检测结果现在会拦住 solve_model。** 判定为「结果不可用」的
> 那几项（见 `silent_failures.RESULT_INVALIDATING`）不通过时，`solve_model`
> 返回 `ok=False` 并在 payload 里给出 `unusable` 字段。这样做不是为了好看，
> 是为了把**自修复闭环**接上——系统提示第 4 条那个"读懂错误、改模型、重试"
> 的循环是靠 `ok` 触发的。以前这些发现只躺在 payload 里，Agent 看到的是
> "求解成功"，于是照样把一套全零结果如实汇报：可溯源，但是个废数。
>
> `excessive_displacement` 有意不在拦截名单里——它的数字是真的，只是大得
> 可疑，用户可能就是要看一个很柔的结构。拦住它等于替用户决定什么叫合理。
>
> 同时修了 `_total_applied_load` 的一处漏算：它原先只统计节点荷载与满跨
> 均布，**跨中点荷载、梯形、局部均布一概不算**，于是 `reaction_load_balance`
> 在任何用了跨荷载的模型上都假报"反力与外载荷不平衡"（实测 11.1% 残差）。
> 支座沉降与初应变则相反——它们不产生净外力但确实是作用，用新的
> `_case_has_action()` 判断，避免把沉降工况误判成空求解。
>
> **这两个假阳性以前都看不见**，因为条件数那个 bug 让 overall 恒为 fail，
> 多一条少一条分不出来。修好一个，底下压着的全露出来了。

> 同日还修了第 5 项 `near_singular_stiffness` 的一个真 bug：它原先拿
> **施加边界条件之前**的总刚算条件数，而那个矩阵按定义就奇异（空间问题恒有
> 6 个未约束的刚体位移模式），于是对**任何**模型都报 critical。
> 一个 100% 误报的 critical 比没有更糟——它让人学会忽略整块告警，
> 真信号跟着一起被埋。现在取自由自由度的子矩阵，口径与 `frame3d.solve` 一致。

## 1. 支座约束不足（insufficient_supports）

### 原理
空间刚体有 6 个自由度（3 个平动 + 3 个转动）。如果支座约束的自由度总数少于 6，或者约束都集中在同一个方向，结构可以做刚体运动——刚度矩阵奇异或接近奇异，求解器可能报错，也可能**给出一个数值极小但方向任意的"位移"**。

### 真实案例
- 一个门式刚架，两个柱底都只约束了 x/y/z 三个平动（铰支座），没有约束转动。平面内载荷下看起来正常，但**面外（y 方向）可以整体侧移**，因为两个铰支座都不能提供 y 方向的抗侧刚度（实际上两个铰点的 y 约束是有的，但绕 z 轴的转动没有约束，结构可以绕 z 轴刚体转动）。
- 更隐蔽的：3 个支座节点，每个只约束 2 个自由度，总数 6，**但 6 个约束全是 x 方向**——结构可以沿 y/z 平动和绕任意轴转动。

### 检测方法
- 统计所有支座的约束自由度总数，< 6 则报警
- 分别检查 x/y/z 三个平动方向是否都有约束
- 分别检查 rx/ry/rz 三个转动方向是否都有约束

### 修复建议
- 空间结构至少需要 6 个约束方向
- 典型配置：一个固定端（6 约束）+ 其他铰支/滚动
- 或：一个铰支座（3 约束）+ 一个滚动支座（1-2 约束）+ 抗扭约束
- 平面刚架可缺少面外转动约束，但必须明确这是设计意图

## 2. 位移过大（excessive_displacement）

### 原理
正常弹性变形下，位移通常远小于结构尺寸（钢材一般 < 1/250 跨度）。如果最大位移超过结构特征尺寸的 10%，几乎可以肯定不是弹性变形，而是**结构在做刚体运动**（约束不足）或**单位错误**（mm 当 m 用，位移放大 1000 倍）。

### 真实案例
- 一个 6m 跨度的门式刚架，柱底约束写成了 `[0,0,0,0,0,0]`（全自由），求解器没报错（因为矩阵非奇异——杆件自身刚度提供了数值稳定性），但跨中位移达到 **2.3m**（跨度的 38%）。
- 单位错误：尺寸用 mm（6000），载荷用 N，材料 E 用 Pa（2.06e11）——刚度被放大了 1e3 倍，位移被缩小了 1e3 倍，反过来如果 E 用 MPa 而尺寸用 m，位移会放大 1e6 倍。

### 检测方法
- 计算结构特征尺寸 = 节点坐标的最大范围（对角线近似）
- 找出所有工况中最大的节点合位移
- 如果最大位移 > 特征尺寸 × 10%，报警

### 修复建议
- 检查支座约束是否完整
- 检查单位一致性：尺寸(m) + 载荷(N) + 材料(Pa) 是一套；尺寸(mm) + 载荷(N) + 材料(N/mm²) 是另一套
- 检查载荷量级是否合理

## 3. 有载荷但反力为零（zero_reaction_with_load）

### 原理
根据平衡方程，外载荷必须由支座反力抵抗。如果有非零外载荷但所有支座反力都接近零，说明**载荷根本没有传到支座**——要么支座约束全是自由端，要么载荷作用在一个与主体结构脱开的自由节点上。

### 真实案例
- 一个框架，梁上作用了 10kN 均布载荷，但柱底约束写成了全自由。求解器"成功"结束，反力全是 0，梁的内力也全是 0——因为整个结构在自由落体，没有任何约束来产生反力。
- 更隐蔽：载荷节点 ID 写错了（写成了一个不存在的节点 ID，或写成了一个与杆件不连接的孤立节点），载荷被"吞掉"了，反力自然为零。

### 检测方法
- 对每个工况，计算外载荷合力（节点集中力 + 均布载荷合力）
- 计算所有支座反力的合力
- 如果外载荷 > 0 但反力 < 外载荷 × 1e-6，报警

### 修复建议
- 检查支座约束是否全为 0
- 检查载荷作用的节点 ID 是否正确、是否与杆件连接
- 检查均布载荷的杆件 ID 是否存在

## 4. 有载荷但内力为零（zero_internal_force）

### 原理
与上一条类似，但更聚焦于杆件。如果有外载荷但所有杆件的轴力、剪力、弯矩都为零，说明**载荷没有传递到任何杆件**——结构是机构（可自由运动），或者载荷作用在孤立节点上。

### 真实案例
- 一个桁架模型，所有节点都用了铰接（释放了所有弯矩），但有一个节间缺少斜杆，形成了一个**机构四边形**。载荷作用下，四边形自由变形，杆件内力全为零（因为没有任何杆件抵抗变形）。
- 刚架模型中，柱与梁的连接全部写成了铰接（releases_i/releases_j 全释放），结构变成了一个机构，载荷下杆件只有轴力（如果几何不变的话），弯矩全为零。

### 检测方法
- 对每个有非零外载荷的工况，遍历所有杆件的内力向量（12 分量）
- 如果所有分量的绝对值都 < 1e-10，报警

### 修复建议
- 检查是否有机构子结构（缺少必要的杆件或约束）
- 检查杆件端部的 releases 是否过度释放（刚架不应释放弯矩）
- 检查载荷节点是否与杆件连接

## 5. 刚度矩阵接近奇异（near_singular_stiffness）

### 原理
刚度矩阵 K 的条件数 `cond(K) = ||K|| × ||K⁻¹||` 衡量求解的数值稳定性。条件数越大，微小的输入误差会被放大成巨大的输出误差。空间刚架的条件数通常在 1e4 ~ 1e8 之间（取决于杆件刚度差异和约束）。如果 > 1e12，说明存在**接近零能的位移模式**（机构运动或极柔杆件），求解结果不可信。

### 真实案例
- 一个塔架模型，底部有一根杆件的截面面积被误写成了 1e-10 m²（几乎为零），这根杆提供的刚度可以忽略，但它的存在让矩阵非奇异。条件数达到 1e15，求解结果中这根杆的内力误差超过 100%。
- 约束不足的结构，K 有零特征值（严格奇异），求解器可能用最小二乘或伪逆给出一个"解"，但这个解没有物理意义。

### 检测方法
- 小矩阵（< 2000 DOF）转稠密，用 `np.linalg.cond` 计算精确条件数
- 大矩阵用范数估计
- cond > 1e12 → critical；cond > 1e8 → warning

### 修复建议
- 检查是否有零刚度或极小刚度的杆件（截面面积 ≈ 0）
- 检查是否有接近机构的子结构
- 检查单位是否一致（刚度差异过大可能是单位混合）
- 考虑增加约束或杆件

## 6. 反力与外载荷不平衡（reaction_load_balance）

### 原理
根据牛顿第三定律，支座反力合力应该与外载荷合力大小相等、方向相反（残差应为零）。如果残差 > 1%，说明有载荷没有被约束抵抗，或者反力提取有遗漏。这是 `check_equilibrium` 的补充检查——`check_equilibrium` 检查的是每个节点的平衡，这里检查的是**整体合力平衡**。

### 真实案例
- 一个多跨框架，中间柱底约束被误删了。梁上的均布载荷通过中间柱传下去，但中间柱底没有反力——载荷"消失"了。整体平衡残差达到 35%。
- 均布载荷的合力计算遗漏了某根杆（比如跨间载荷 `member_spans` 没有被计入外载荷合力），导致残差看起来不平衡，但实际上求解是对的。

### 检测方法
- 对每个工况，计算外载荷合力（节点力 + 均布载荷 + 跨间载荷）
- 计算支座反力合力
- 残差 = ||外载荷 + 反力|| / ||外载荷||
- 残差 > 1% → 报警

### 修复建议
- 检查是否有支座约束被遗漏
- 检查载荷类型是否都被计入（nodal_loads / member_loads / member_spans）
- 结合 `check_equilibrium` 的逐节点残差定位问题

## 7. 载荷量级异常（load_magnitude_anomaly）

### 原理
结构工程中，应力 = 载荷 / 面积。典型钢结构的应力在 10~200 MPa 之间。如果估算应力超过材料弹性模量的 10%（钢约 20 GPa），物理上不可能（材料早已屈服或断裂）——这通常是**单位错误**（kN 当 N 用，载荷放大 1000 倍）。反过来，如果应力 < 0.001 Pa，可能是 N 当 kN 用（载荷缩小 1000 倍）。

### 真实案例
- 一个梁模型，载荷写成了 10（以为是 kN，实际代码里是 N），材料 E = 2.06e11 Pa。估算应力 = 10N / 0.01m² = 1000 Pa = 0.001 MPa——位移极小，看起来"刚度很大"，但实际上是载荷小了 1000 倍。
- 反过来，载荷写成了 10000（以为是 N，实际是 10kN），估算应力 = 10000N / 0.0001m² = 1e8 Pa = 100 MPa——正常。但如果截面是 0.01m²，应力 = 1MPa，也正常。关键是**量级一致性**。

### 检测方法
- 取典型材料弹性模量 E
- 估算典型截面积（默认 0.01 m²）
- 估算应力 = 外载荷合力 / 典型面积
- 应力 > 0.1 E → 载荷过大（可能 kN 当 N）
- 应力 < 1e-3 Pa → 载荷过小（可能 N 当 kN）

### 修复建议
- 统一单位制：m + N + Pa，或 mm + N + N/mm²
- 检查载荷数值是否合理（10kN 的梁载荷 vs 10N 的梁载荷）
- 检查材料 E 的单位是否与尺寸单位匹配

## 8. 截面主轴方向风险（section_orientation）

### 原理
梁截面有两个主轴：强轴（绕 z 轴，Iz，抗弯刚度大）和弱轴（绕 y 轴，Iy，抗弯刚度小）。通常 Iz > Iy（比如工字钢，Iz 远大于 Iy）。如果 Iy > Iz，可能是：
1. 截面定义时 Iy 和 Iz 写反了
2. 杆件的 `ref_vector` 方向错误，导致局部坐标系旋转了 90°，原来的强轴变成了弱轴

### 真实案例
- 一个工字钢截面，正确的 Iz = 1.2e-4 m⁴，Iy = 5.6e-6 m⁴。但定义时写反了（Iy = 1.2e-4, Iz = 5.6e-6），梁在竖向载荷下绕"弱轴"弯曲，位移放大了 21 倍。
- 更隐蔽：截面定义正确，但某根梁的 `ref_vector` 写成了 (0, 1, 0) 而不是 (0, 0, 1)，导致局部 y/z 轴互换，强轴弱轴颠倒。

### 检测方法
- 遍历所有截面，如果 Iy > Iz × 1.5，报警
- 列出使用该截面的杆件，提示检查 ref_vector

### 修复建议
- 检查截面特性的 Iy/Iz 是否写反
- 检查杆件的 ref_vector 定义（ref_vector 决定局部 y 轴方向，应指向截面弱轴方向）
- 对于竖向受弯的梁，ref_vector 通常取 (0, 1, 0)（y 轴水平），使 Iz 绕水平 z 轴（强轴抗弯）

## 使用方法

### 代码调用
```python
from silent_failures import detect_silent_failures, format_findings

model = from_dict(payload)
sol = solve(model)

findings = detect_silent_failures(model, sol)
print(format_findings(findings))

# 只跑某几项
findings = detect_silent_failures(model, sol, only=["excessive_displacement", "zero_reaction_with_load"])

# 排除某几项
findings = detect_silent_failures(model, sol, exclude=["load_magnitude_anomaly"])
```

### MCP 工具
```
detect_silent_failures_tool(model_json: str) -> str
```

### CLI（通过胶囊）
```bash
python -m capsule save examples/portal_frame.json --label "测试"
# 胶囊中包含静默失败检测结果
```

## 设计原则

1. **宁可误报，不可漏报** — 静默失败的代价远大于一次误报。所有检测项的阈值都偏保守。
2. **每项检测都给出具体数值** — 不只是"有问题"，而是"位移 2.3m，结构尺寸 6m，占比 38%"。
3. **每项检测都给出修复建议** — 不只是诊断，还要告诉用户怎么修。
4. **检测工具自身的错误不影响求解** — `detect_silent_failures` 内部 try/except，检测出错只返回 warning，不中断流程。
5. **与平衡校核互补** — `check_equilibrium` 检查逐节点平衡，这里检查整体量级和结构合理性。
