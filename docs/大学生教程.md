# 空间刚架智能计算 Agent · 上手教程（大学生版）

**读者假设**：学过材料力学与结构力学，知道什么是刚架、弯矩、支座反力；
不假设你会写程序，也不假设你用过任何 CAE 软件。

比《使用手册》深一层：那本只讲"怎么点出结果"，这本还讲**每个功能背后在算什么、
什么时候该用、什么时候它会拒绝你**。全篇约 40 分钟读完，配合软件边看边点最有效。

---

## 0 一分钟认识它

一句话：**你用自然语言或者鼠标描述一个空间刚架，它算出位移、内力、应力，
并且每个数字都能追到某一次确定性的求解器调用。**

它不是"AI 算结构"。大语言模型在这里只负责**把你的话翻译成一次工具调用**，
所有数值都出自自研求解器。系统提示里第一条硬规则就是"你不做任何数值计算"。

### 能算什么

| 能力 | 说明 |
|---|---|
| 空间刚架静力 | 12 自由度梁单元，Euler-Bernoulli；给了有效剪切面积则转 Timoshenko |
| 杆端释放 | 铰接/部分释放，用静力凝聚实现，不是"删自由度" |
| 刚域偏移 | 节点区刚性段 |
| 多工况与组合 | 总刚一次分解、逐工况回代 |
| 自振特性 | 频率与振型（需要密度） |
| 线性屈曲 | 临界荷载因子与失稳模态 |
| 二阶弹性 P-Δ | 小应变二阶，不是几何大变形 |
| 轴向材料非线性 | 双线性，仅轴向；弯曲仍弹性 |
| 温度与初应变 | `Δl = α·ΔT·l` |
| 强度与稳定校核 | 逐杆 σ/[σ]、折算应力 √(σ²+3τ²)、材力四个强度理论、欧拉 Pcr、GB 50017 稳定系数 φ |
| 节点应力集中 | 局部 C3D10 实体子模型 |

### **不**能算什么（这一栏和上一栏一样重要）

- 不是几何大变形（`NLGEOM`）；P-Δ 是小应变二阶弹性
- 弯曲塑性、塑性铰、推覆分析都没有
- 梁的云图是**中心线内力**着色，不是连续体应力云图
- 剪应力与 von Mises 等效应力没有（截面契约里缺一次矩和壁厚）
- 不接任何设计规范，算出来的 σ/[σ] 不是规范验算结论
- 动力时程没有

**答辩和用它做作业时，这一栏要说得出来。** 一个说不清自己边界的程序，
算得再准也没人敢用。

## 1 三分钟跑通第一个算例

### 1.1 启动

| 你手上是 | 双击 |
|---|---|
| `FrameLab` 文件夹 | 里面的 `FrameLab.exe`（整个文件夹要留着） |
| 项目源码 | `run_desktop.bat` |

起不来先跑 `python -m desktop.app --doctor`，它逐项体检并用中文说哪一项坏了。

### 1.2 建一个规则框架

功能区 **`建模` → 「规则框架」**（快捷键 `Ctrl+F`）。对话框里几个关键输入：

- **跨度**：填一串数，空格分开。`6 6` 表示两跨、每跨 6 米（**不是"跨数=6"**）
- **层高**：同理，`3.6 3.6 3.6` 是三层
- **进深**：同上
- 底下有个**「生成时同时指派属性、柱脚与荷载」**的勾选框，**默认不勾**。
  新手建议勾上，它会顺手把材料、截面、固定柱脚和一个均布工况配齐，
  省掉后面四步。

确定之后视口里就有一个三维刚架了。

### 1.3 求解

在「作业」页点「求解」（或 `F5`）。页签行右端的「流程」菜单和下一步按钮
按实际模型状态提示下一项操作，校验失败时先修正问题。

### 1.4 看结果

- `Ctrl+2` 变形图（会自动放大，否则肉眼看不见）
- `Ctrl+3` 内力云图
- 「结果」小窗换分量、换色系、定位极值

到这里你已经跑完一次完整分析。下面逐块讲细节。

## 2 界面地图

### 2.1 功能区（顶部十一个页签）

按**任务阶段**排，从左往右点一遍就是一次完整分析——这是 CAE 的通行组织方式。

| 页签 | 里面有什么 |
|---|---|
| `项目` | 新建/打开/保存、Agent 对话开关、导出学习轨迹 |
| `建模` | 草图建模、图纸识别、草图识别、规则框架、门式刚架、模型表格、模型 JSON |
| `属性` | 创建材料、创建截面、截面管理器、属性指派、批量属性指派、梁截面方向、单位制 |
| `装配` | 装配检查、命名集合、独立实例、线性阵列、环形阵列与实例管理器 |
| `分析` | 求解设置、静力/P-Δ/频率/屈曲分析步、幅值曲线 |
| `连接` | 杆端刚接、释放、转动弹簧；刚性连杆、TIE、PIN与运动耦合 |
| `载荷` | 边界条件及载荷对象、给定位移、重力、工况与荷载组合 |
| `网格` | 全局布种、杆件布种与梁网格映射；局部实体网格另行设置 |
| `作业` | 作业创建、检查、提交、消息与结果；独立工况及分析步求解、停止、屈曲与节点实体 |
| `结果` | 结果表、单杆及路径曲线、动画、包络、挠度、报告、强度验算与截面优化 |
| `视图` | 视口背景、截面渲染、显示组、荷载数值、截图、中 / EN |

人工建模可打开全流程清单，按九阶段检查当前定义。已指派不等于已复核，模型修改后旧确认与网格预览失效。批量连接按局部轴设置，保持原值不改动其他方向；转动弹簧需给出有依据的绝对刚度。

独立工况用普通求解，声明步骤用提交分析步；结果树保留各步结果，单击步或帧即可查看，无需重新求解。
各步从无应力状态重解，不代表施工过程或塑性历史。详细操作见使用手册3.0节。

### 2.2 常驻快捷栏（功能区下面那一条）

分三段，**每个按钮都带文字**——纯图标认不出来。

| 段 | 内容 | 什么时候在 |
|---|---|---|
| 左（固定） | 前视/侧视/顶视/等轴测/适应窗口、撤销/重做 | 一直在 |
| 中（随阶段变） | 建模时：选择节点/杆件、建节点/建杆件/删除选中<br>看结果时：**工况下拉**、**变形放大系数** | 按当前页签与显示模式切换 |
| 右（固定） | 显示模式：`模型` `分析网格` `变形` `云图` `模态` | 一直在，当前模式高亮 |

三点值得说明：

- **中段为什么要换**：建几何时没有结果可切，审结果时不会去建节点。
  两套控件原先同时常驻，同屏十几项，一多半是当前用不上的。
- **工作平面 / 捕捉 / 坐标建点**只在勾了「建节点」或「建杆件」时才出现。
  它们只影响"下一个点落在哪儿"，不放点的时候没有意义。
- **显示模式是状态不是动作**，所以做成一排互斥按钮而不是普通图标——
  你随时能看出自己在看模型还是在看云图。`分析网格` 也在这里，
  它是一种显示模式，不在「分析」页里重复放一份。

功能区可以收起：**双击页签**，或点页签行右端的 `⌃`。
收起后只留页签（高度 112px → 33px），把地方让给视口；页签始终保留，
因为它同时是"我在哪个模块"的指示。

### 2.3 流程菜单与命令面板

页签行右端保留「流程」菜单、下一步主按钮与「AI 助手」开关。
流程按建模、定义、校验、求解、结果组织，下一步所属页签前有绿色箭头（已在该页时不显示，当前页只用下划线标出）；底部显示校验问题和拾取说明。
Ctrl+Shift+P打开「命令面板」，可按中文或英文搜索命令，找不到时可将需求交给AI助手。

### 2.4 模型侧栏与独立结果窗口

模型栏、三维视口与AI助手并排，结果明细默认在独立窗口查看：

- **左侧模型栏**：模型树在上、属性在下，常驻并占用布局宽度。树中单击高亮对象，右键打开对象管理；材料、截面、集合、分析步、约束、装配及作业按类型组织，各类带图标与展开箭头，尚未定义的空分类以浅灰显示。
- **并排对话**：AI助手在视口右侧，可拖动分隔线调整宽度；页签行右端按钮切换显隐。顶栏左边是当前模型，右边四个图标依次为「对话记录」「新建」「协作任务」「连接设置」（悬停显示名称）。用户消息靠右显示为气泡，连续几次工具调用收成一张写明调用链的卡片，点开逐次查看参数与结果。输入框下方的「引用对象」「加入所选」是按钮，右下角圆形按钮发送，运行中变为停止（Esc）；空输入框按↑取回上一条消息。
- **结果弹窗**：结果表、单杆内力图和截面优化，从结果页打开，可移动、缩放，关闭后从原入口重开。
- **草图弹窗**：手绘草图识别，从建模页的草图识别命令打开。

三条规矩：

* **模型栏与AI助手直接参与布局**，拖动分隔线改变可用视口，左右窄栏已移除。
* **辅助面板按对应命令打开**。
  结果表和单杆内力图默认独立打开，不占底部，也不调整模型相机。小屏幕弹窗初始不超过
  可用屏幕宽度的80%、高度的75%；宽表格可滚动查看，仍可手动放大。
* **Esc 收起最后打开的那个抽屉**（在拾取或建模模式里时先退出那个模式）。
  抽屉内侧的边可以拖动改宽高。
  独立窗口内按Esc只关闭该窗口，数据与选择保留；也可以手动停靠回底部。

求解完成后结果先画在模型上，**结果表不会自动弹出**——各工况的最大位移、
挠度和平衡检查已经填好在「结果」里，想看数字时再点。

**AI 助手默认并排显示**，密钥与连接表单在独立窗口配置；小屏幕保留输入与对象选择，会话切换收进菜单。

## 3 建模：五条路径

**都通向同一个模型对象**，选顺手的那条。

### 3.1 参数化（最快）

`建模` → 「规则框架」/「门式刚架」。规则结构直接生成。

### 3.2 草图拉伸（Abaqus 式）

`建模` → 「草图建模」（`Ctrl+K`）。二维画一榀框架，沿进深拉伸成三维。
适合平面规则、进深重复的结构。

### 3.3 手工建模

拾取过滤器先定**选什么**再点：`N` 只选节点，`M` 只选杆件。
然后「建节点」（`Ctrl+Shift+N`）在视口里点位置，「建杆件」（`Ctrl+M`）
点两个节点连一根。

配合 **工作平面**（XY/YZ/XZ + 偏移 z=）和**捕捉**用，否则三维里点不准。

### 3.4 表格 / JSON

`建模` → 「模型表格」（`Ctrl+T`）七张表直接编辑，支持 CSV 导入导出；
或「模型 JSON」直接改原始数据，写回前会做结构校验。

**从别的软件导数据时走这条。**

### 3.5 结构图纸识别（多模态）

`建模` → 「图纸识别」（`Ctrl+I`）。上传平面图、立面图与截面表，得到一份通过模型校验的模型 JSON。

这条路径的设计和"让 AI 看图建模"正好相反：**数值从不来自 AI 的判断**。
AI 只照抄图上的文字（轴号、"6000"、"3.600"、"HN400×200×8×13"、"柱脚刚接"），
每条附带出处；代码把间距累加成轴线坐标、标高给出 z，梁沿轴线逐跨拆分、柱在交点逐层拆分，
规格交给截面构造器算特性，材料按规范表取弹性模量（钢材 GB 50017-2017 表 4.4.8，
混凝土 GB 50010 表 4.1.5）并要求确认。图上没写的单位、间距、柱脚做法一律进核对表让你填，
不按惯例默认，也不从像素量。分段间距之和与总尺寸不符、某段间距在图上的长度比例离群
（多半是 6000 被抄成 8000），都会被拦下。

判读要点：核对表全部处理完才会生成；导入后检查模型树里的节点、杆件数与图纸一致，
再加荷载求解。H 型钢规格不含根部圆角 r，截面面积比型钢表小约 2%～3%，需要时在「创建截面」中补 r。

### 3.6 手绘草图识别（多模态）

`建模` → 「草图识别」。上传没有尺寸标注的手绘图，AI 给出识别覆盖层，
**你逐条核对并编辑**，标定尺度后再加载。

注意这条路径的定位：**它是"帮你少打字"，不是"帮你看懂图"**。
识别结果一律要你确认，因为识别错了是静默的——生成的模型合法，只是不是你画的那个。

## 4 属性：材料与截面

CAE 的经典顺序：**先有材料 → 再有截面 → 再指派给杆件**。

### 4.1 创建材料

`属性` → 「创建材料」。必填弹性模量 `E`、泊松比 `ν`、密度 `ρ`。

下面还有一组**「强度验算与温度（可选）」**：

| 字段 | 不填的后果 |
|---|---|
| 许用拉应力 / 许用压应力 | **强度验算会被拒绝**，不是给你个估计值 |
| 屈服应力 | 稳定校核的 λp 算不出来 |
| 线膨胀系数 α | 温度荷载算不了 |

拉压许用是**分开**的：铸铁、混凝土这类材料两者差很远，合成一个就错了。

### 4.2 创建截面

`属性` → 「创建截面」。选类型（工字/箱形/管/矩形/圆等）填尺寸，
程序自动算 `A / Iy / Iz / J`，**并且算出 `cy / cz`（极端纤维距离）**。

**这一点很关键**：如果你直接填 `A/I/J`（截面管理器里可以），
程序就没有 `cy/cz`，于是：

- **应力云图会被拒绝**
- **强度验算会被拒绝**

不是算不出来就估一个，是明确告诉你缺什么。想要应力就用「创建截面」按尺寸建。

> 偏心截面（如 T 形、角钢）不给 `cy/cz`：它们形心不在几何中心，
> 单个"极端纤维距离"表达不了，预览里会解释原因。

### 4.3 属性指派

`属性` → 「属性指派」。选中杆件 → 一次指派材料与截面。
这是 Abaqus Property 模块的核心操作。

### 4.4 截面朝向（**最容易静默出错的一处**）

强弱轴悬殊的截面（如 400×200 工字钢，`Iz/Iy ≈ 13`），
**如果局部 y 轴朝向反了，弯矩分量全部张冠李戴，程序一声不吭。**

- 想看某根杆的局部轴：选中它，属性面板里有局部 x/y/z 三色箭头（x 红 y 绿 z 蓝）
- 生成器会给竖直杆显式写入参考向量，避免 0.01°/0.1° 之间翻号
- 手工建模时若发现弯矩分量不对，**第一个要怀疑的就是这里**

### 4.5 单位制

`属性` → 「单位制」在 `N-m-Pa` 与 `N-mm-MPa` 之间**整份模型转换**，
不是只改显示。状态栏右下角常驻显示当前单位制。

## 5 边界条件与荷载

### 5.1 支座

`载荷` → 「创建边界条件」。选中节点，勾 `U1/U2/U3/UR1/UR2/UR3` 六个自由度。
全勾是固接，只勾三个平动是铰接。

> 视口里**不是每个受约束节点都画符号**：平面刚架的面外自由度是代码自动约束的，
> 全画出来满屏符号，真正的柱脚反而看不见。只画约束住两个及以上平动方向的节点。

### 5.2 荷载

`载荷` → 「创建载荷」：集中力、线荷载、重力，选中对象后输入分量。
杆中的集中力、只压一段的均布或梯形荷载选「杆上集中力」「区间均布荷载」「区间梯形荷载」，
位置按「距 i 端距离」或「全局坐标」给。
「重力」按密度和截面面积自动算自重。

荷载箭头旁边默认标数值。模型一大会糊成一片，`视图` → 「荷载数值」
（`Shift+L`）整体关掉，箭头保留。

### 5.3 工况与组合

`载荷` → 「荷载组合」按分项系数组合。求解一次算完所有工况——
总刚只分解一次，逐工况回代，这是多工况的全部好处所在。

## 6 分析步、对象与作业

`分析` → 「分析步」创建并管理步骤：

| 类型 | 什么时候用 | 注意 |
|---|---|---|
| 线性静力 | 初始模型的独立静力平衡 | 荷载属于工况，分析步激活工况 |
| P-Delta 二阶弹性 | 轴压大、侧移敏感的框架 | 小应变，非通用大变形；不继承塑性历史 |
| 频率 | 自振频率、振型与参与质量 | 需要密度；线性摄动步修改不向后传播 |
| 屈曲 | 参考荷载下的临界放大倍数与模态 | 线弹性上限，不能直接作为设计承载力 |

普通求解设置中仍提供双线性轴向材料分析，仅轴向塑性、弯曲弹性，不能把多工况非线性结果事后叠加。
「模态」（Ctrl+4）显示振型，「屈曲」入口可单独执行特征值分析；
统一流程是在分析步中定义，再通过作业管理器提交。作业保存模型指纹、状态和消息；会话仅保留当前结果，模型变化或结果被其他作业覆盖后须重新提交，不支持多作业快照对比。

- **「模态」**（`Ctrl+4`）：自振频率与振型，**需要材料密度**。
  一致质量阵会**高估**频率，这是该做法的真实精度，不是 bug。
- **「屈曲」**：线弹性屈曲因子与失稳模态。一致几何刚度阵必然**高估**临界荷载，
  加密时从上方单调逼近欧拉解——**误差的符号本身就是一条校验**。

> **这两项必须把跨拆细，一跨一个单元是不够的。**
>
> 静力内力是解析恢复的，与网格无关；但一致质量阵和几何刚度阵靠形函数装配，
> 网格越粗报得越高——**偏不安全那一侧**。实测：
>
> | 模型 | 每跨单元数 | 结果 | 收敛值 | 偏差 |
> |---|---|---|---|---|
> | 单跨门式刚架（屈曲） | 1 | λ=1.66 | λ=0.82 | **+102%** |
> | 单跨门式刚架（屈曲） | 2 | λ=0.8229 | λ=0.8229 | 0% |
> | 8 m 简支梁（屈曲） | 1 | — | — | +21.6% |
> | 8 m 简支梁（模态 f1） | 1 | 8.24 Hz | 7.43 Hz | +11.0% |
> | 8 m 简支梁（模态 f1） | 4 | 7.4278 Hz | 7.4259 Hz | +0.026% |
>
> 第一行是要命的那个：λ=1.66 在说还有 66% 余量，而真相是 λ<1，
> **它已经失稳了**。`generate_frame` 生成的恰好是每构件一个单元，
> 所以这是最容易撞上的情形。
>
> 当前频率、屈曲与P-Δ分析会按每根杆件至少4段自动加密，用户布种要求更细时取更细的网格。
> 原有粗网格对照说明为什么不能把一根杆直接当成一个分析杆段；自动加密仍不能替代收敛检查。
> 网格不够时，屈曲与模态的结果里会多一个
> `mesh_warning`，写明是哪一跨、几个单元、偏差多大。屈曲因网格太粗而解不出
> 临界因子时，`likely_cause` 会直说是单元太少，而不是把你指向荷载方向。
> 每跨拆到 4 个单元以上就不再提示。

边界条件、荷载、截面指派及梁方向是作用于区域的命名对象。区域写集合名时是活引用，
修改集合会触发再生成；对象与旧式逐节点直接定义的条目不能重叠覆盖。
旧支座可从模型树一键转换成边界条件对象，转换保持数值模型并可撤销。
管理器按分析步显示创建、传播、修改、失活；给定位移仅在Initial创建，指定工况，且只能作用于固定方向。

连接约束用主从自由度消元处理。BEAM刚性连杆、TIE、PIN与运动耦合覆盖偏心连接、重合节点连接和刚性楼板。
重叠从自由度、从节点支座冲突及约束环会被拒绝。实例阵列只复制杆系及属性，不复制装配荷载与边界条件。

三维屈曲扫描应先核对控制模态。保持GJ不变而只增大极惯性矩时，纯扭转临界力可能降低；
“截面越大临界因子必然越大”只适用于相应的弯曲控制条件，不能据此删掉有效模态。

## 7 求解与校验

### 7.1 两级算前校验

点「求解」之前，程序先做确定性完整性校验：有没有杆子悬空、有没有地方
没固定、材料截面有没有漏指派。**不通过就不让求解**，问题逐条列在下方。

这不是挑剔。奇异刚度矩阵不一定抛异常——荷载恰好不激发那个刚体方向时，
它会安静地返回一个看似合理、连平衡校核都能通过的错误位移场。
**所以要在算之前拦，不能指望求解器替你发现建模错误。**

### 7.2 算后自校核

求解完自动做：

- **整体六分量平衡校核**：`ΣF = 0`、`ΣM = 0`
- **奇异诊断**：矩阵奇异时给出零空间方向，并翻译成人话
  （"这根杆绕自身轴自由转动，缺 UR1 约束"）

### 7.3 模型检查

`分析` → 「模型检查」是 AI 辅助的：孤立节点、重复杆件、缺支座、缺荷载，
给出修正建议。和 7.1 的确定性校验是两回事——那个是硬闸，这个是建议。

## 8 结果判读

### 8.1 变形图（`Ctrl+2`）

自动按模型尺寸选放大系数，快捷栏里可手动改。
**判断"这个变形是真的大还是被放大了"，就靠手动调它。**

变形曲线用的是**单元内解析挠度**，不是节点位移连直线——
否则单跨一个单元的梁会画成直线，跨中那个鼓看不见。

### 8.2 内力云图（`Ctrl+3`）

结果面板上五个开关：

| 开关 | 含义 |
|---|---|
| **内力分量** | N / Vy / Vz / T / My / Mz / 合剪力 \|V\| / 合弯矩 \|M\| / σ |
| **云图量程** | 95% 裁剪 或 满量程。一两根杆特别大时用裁剪 |
| **分级** | 6~24 级色块。连续渐变只看得出"这边比那边红" |
| **色系** | 彩虹（Abaqus 式）/ 蓝—灰—红 / 单蓝 |
| **立体** | 打光。要严格照色标读数就关掉 |
| **符号** | 全部 / 仅正值 / 仅负值 |

几条判读规则：

- **合量（\|V\|、\|M\|）定义上非负**，用顺序色标，从零起
- **有符号分量关于零对称**，中点是零
- 超出量程的段单独画成**橙色**，否则峰值位置会消失在饱和的同色里
- 彩虹色系明度不单调，**黑白打印和色盲读不出高低**，那两种场合换另外两套

> **σ 是极端纤维正应力** `σ = N/A ± M·c/I`，不含剪应力与扭转，
> 所以**不是 von Mises**。截面缺 `cy/cz` 时点它会被当场拒绝。

### 8.3 内力图（`Ctrl+D`）与包络

- 「内力图」：沿杆长的曲线，峰值位置、过零点、各组合包络
- 「包络」：各分量沿杆件的极值与**控制组合**
- 「最大挠度」：最不利杆件的挠度、位置与**挠跨比**

### 8.4 定位

结果表里点一行 → 视口高亮那根杆。「定位当前分量极值」直接跳到峰值位置。
`L` 键打开编号标注，报错和结果定位时必备。

## 9 四项校核

这四项对应课程讲义《程序灵活应用及讨论》的具体条目，是这个程序区别于
"能算就行"的地方。

### 9.1 强度验算

`结果` → 「强度验算」。逐杆给出：

- **应力比 σ/[σ]**，拉压许用分开算，取较大者
- **折算应力 √(σ²+3τ²)**，即第四强度理论，也是 GB 50017 §6.1.5 的式子
- **材力四个强度理论**的相当应力 σr1~σr4，一并列出
- **受压杆的欧拉临界力** `Pcr = π²EI/(μl)²`，长细比 λ
- **GB 50017 稳定系数 φ** 与 `N/(φA) ≤ f`

#### 为什么正应力不够

只看正应力会漏掉剪切控制的构件。实测同一根 HN400，总荷载不变、只改跨度：

| L/h | 纯正应力 σ | 折算应力 σr4 | 控制点 | 倍数 |
|---|---|---|---|---|
| 15.0 | 117.57 MPa | 117.57 MPa | 极端纤维 | 1.00 |
| 5.0 | 39.19 MPa | 54.56 MPa | 中性轴 | 1.39 |
| 2.5 | 19.60 MPa | 54.56 MPa | 中性轴 | **2.78** |

L/h=2.5 那根，只看正应力是 19.6 MPa、应力比 0.064，"安全得很"；
真实折算应力 54.6 MPa。控制点在**中性轴**——那里弯曲 σ=0 而 τ 最大，
正应力校核永远看不到。

折算应力在**三个特征点**分别取值再合成：极端纤维（σ 最大、τ=0）、
中性轴（σ 只剩 N/A、τ 最大）、腹板边缘（两者同时都大）。
**不是**拿 σmax 与 τmax 凑成一个数——那个组合在截面上并不存在。

#### 为什么欧拉不够

欧拉公式在 λ<λp 时给出的 σcr 已超过屈服应力，没有物理意义。麻烦在于
**实际钢柱大多恰好落在那一段**。实测一根 λ=24.9 的粗短柱：

```
欧拉  N/Pcr        = 0.023   ← 看着安全到离谱
规范  N/(φA)/f     = 0.822
```

差 35 倍，而且是偏不安全的方向。现在这一段由 GB 50017 附录 D 的 φ 系数法
接手，覆盖全柔度范围：λ→0 时 φ→1（强度控制），λ 大时贴近但始终**低于**
欧拉值（真实柱有初弯曲与残余应力，只会更弱）。

截面类别 a/b/c/d 不是细节：λ=80 时 a 类 φ=0.783、d 类 0.493，差 59%。
默认取 b 类（热轧工字钢、H 型钢绕强轴的常见归类），判不准时显式指定。

**结论仍然有三档不是两档**：

| 结论 | 含义 |
|---|---|
| 通过 | 没问题 |
| 超限 | 真的不够，行标**红** |
| **判不了** | 行标**琥珀色**：现在只在**连规范法也算不了**时才出现（材料没给屈服应力） |

第三档的范围比以前小得多。早期版本把"欧拉公式不适用"算成不通过，结果一个
普通两层框架十根杆里八根报"不安全"；后来改成"判不了"，而那时中小柔度
几乎全落进这一档。现在 φ 接手，只剩真正缺参数的情形。
**软件宁可说"我判不了"，也不给一个来路不明的数——这条没变。**

> `μ` 的取值只适用于**无侧移**框架，界面上有明确警告。
> 另外 Pcr 是按**物理构件整根**算的，不是按剖分后的分段——按分段算会偏大四倍。

### 9.2 对称性

`结果` → 「对称性」。检测结构与荷载的对称面，并用对称位置的位移
**互为镜像自校核**结果（门式刚架实测 2e-16）。

**这是一条不需要任何外部参照的校验。** 注意力矩是轴矢量，
镜像规则与力相反——法向分量的处理正好反过来。

程序**有意不做半结构简化**：简化能省的那点算力，远不如"整结构算完再用
对称性校核自己"值钱。

### 9.3 编号与存储

`结果` → 「编号与存储」。给出节点编号的半带宽、RCM 重编号后的改善，
以及**满阵 / 等带宽 / 一维变带宽 / 稀疏**四种总刚存储量对比。

这是教学对照路径：同一个结构只把节点号对调一遍，半带宽能从 65 变成 563，
存储量从 3.5 万变成 12.5 万。**程序不会偷偷改你的节点编号**，只告诉你代价。

**能力边界写在前面**：

- 当前支持八类参数截面和带孔多边形；要求同材料、无刚域偏移与线性静力整体解；局部几何仍需正确反映结构

- 保留区集中力、力矩和线荷载已按静力等效加载区重建；未重建的温度场和内部支承仍拒绝，不能漏载后给出应力
- 几何不含焊缝倒圆时，相贯线是**应力奇异点**，峰值随网格加密**无上界**
- 所以 Kt 一律以 **IIW 0.4t/1.0t 线性外推的热点应力**为分子
- 拿不到热点应力就**明确拒绝**，不报一个随网格变的假数
- 收敛判据是三档网格 + 发散识别，不是"两档差 5% 就算收敛"
  （那个判据会把奇异问题误判成收敛）

## 10 AI 面板怎么用

`Ctrl+G` 显示或隐藏并排对话面板。

### 10.1 它能做什么

- 把"两跨三层、跨度 6 米、层高 3.6 米、梁上均布 20 kN/m"变成一次建模调用
- **信息不全时主动追问**，而不是套个默认值算下去
- 求解奇异时，把零空间方向翻译成"哪根杆缺什么约束"
- 改模型前给出**结构化 diff 预览**，你确认了才应用；删除类操作强制预演

### 10.2 它不做什么

**不做任何数值计算。** 位移、内力、反力、应力的每一个数字都来自工具返回值。
这是系统提示里的第一条硬规则，也是"你怎么知道它没在编"的答案——
不是靠事后检查，是**结构上不给它胡说的机会**。

它也必须**原样转达限制与警告**：不许把"判不了"说成"通过"。

### 10.3 没配密钥时

进入**离线演示模式**：对话按预设意图分派（建模求解、挠度、控制组合、稳定、
自振、出报告六类），但**工具调用与求解都是实际执行的**，不是假数据。

配密钥的方法：在对话面板打开模型连接设置，可粘贴密钥或导入单行 UTF-8 密钥文件，
选择提供商协议、基础地址与实际模型标识。Windows 可使用当前用户安全存储；仅本次运行模式不保存密钥。
先读取模型目录，再检测工具调用，最后保存并使用。目录成功不代表工程工具可用；检测产生一次固定模型请求。
环境变量 DEEPSEEK_API_KEY 与程序目录下的 deepseek.key 仍可使用。程序只显示密钥来源或短指纹。

切换模型保留历史与工程；对话及其模型上下文可在本地保存并于重启后恢复，所有会话共用当前工程。聊天历史不代表已恢复当时的工程模型。
选择工程对象窗口支持搜索与多选，或在视口选中后显式加入对话；模型修改后必须重新选择引用。
点击 Agent 任务进入真实协作窗口：主Agent组织步骤，建模与检查子Agent使用独立Session和受限工具。
缺参选项先填入输入框再继续任务，停止或网络失败可在本次运行恢复，预算累计不重置。
检查使用指定候选的真实工具，不直接改变原工程；预览差异并明确应用后才写入主模型，原有分析结果失效。
人工编辑会使旧基线失效，任务记录保留模型版本、工具参数和结果。离线只检查已有模型，不代替自由在线任务。
知识库检索、跨运行恢复与参数比较界面仍未接入。

## 12 常见"被拒绝"及其含义

这个程序拒绝你的时候，通常是在保护你。

| 提示 | 真正缺的东西 | 怎么办 |
|---|---|---|
| 无法绘制应力云图 | 截面没有 `cy/cz` | 用「创建截面」按尺寸建，别直接填 A/I/J |
| 强度验算被拒绝 | 材料没有许用应力 | 「创建材料」里勾上那组可选字段 |
| 校验不通过，不能求解 | 悬空杆 / 缺支座 / 漏指派 | 看下方问题面板逐条修 |
| 稳定判不了（琥珀色） | 没缺东西 | λ<λp，欧拉公式不适用，这是**正确结论** |
| 节点实体拒绝报 Kt | 热点应力外推不出来 | 几何是奇异的，加密也没用 |
| 模态算不了 | 材料没有密度 | 补 ρ |

## 14 撤销与建模过程

`Ctrl+Z` 撤销上一步（结果会一并清除——模型变了旧结果就不再有效）。

`Ctrl+H` 打开「建模过程」，**逐步回看整个建模历史，双击任意一步跳回那时的
模型状态**。

这个功能的存在理由很直接：**Agent 一轮就能改动整个模型。没有退路，
你每次回车前都要犹豫；有了退路，才敢放手让它试。**

## 16 三个建议

1. **先信平衡校核，再信云图。** 云图好看不代表算对了；六分量平衡过不了，
   再漂亮的图也是错的。
2. **强弱轴悬殊的截面，一定检查一次局部轴。** 这是唯一一类"数值合理但全错"
   且程序不会报错的问题。
3. **遇到"判不了"别急着绕过去。** 那一档是程序在告诉你"这个方法回答不了
   这个问题"，绕过去等于给自己一个来路不明的结论。
