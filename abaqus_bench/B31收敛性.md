# B31 那组为什么对不上：是离散误差，不是格式差异

**2026-09-16 查清。** 此前 `benchmark_B31.md` 把偏差归因于"两种梁理论的格式
差异"，那个解释对 `u3` 成立，对其余分量**不成立**——现在有更准确的答案。

## 现象

`space_frame` 算例里，Abaqus 的 B31 把整个水平向与绕 X 转的响应算没了，
而同一份输入只把 `TYPE=B33` 换成 `TYPE=B31`（两份 `.inp` 的 diff 除此之外
没有一行不同）：

| 分量 | 本程序 | B33 | B31（一根杆一个单元） |
|---|---|---|---|
| `u1` | 1.3314e-04 | 1.3314e-04 | 7.72e-06（**差 17 倍**） |
| `u2` | 1.4032e-05 | 1.4032e-05 | 1.87e-19（**机器零**） |
| `ur1` | 3.7945e-03 | 3.7943e-03 | 0.0（**机器零**） |
| `rf2` | 4.8017e+03 | 4.8010e+03 | 1.17e-13（**机器零**） |
| `u3` | 1.5204e-03 | 1.5204e-03 | 1.5078e-03（差 0.8%） |

竖向（`u3`）只差 0.8%，符合 README 里"细长构件下约 1e-3"的预期；
但其余分量差了几个数量级，**远超"格式差异"能解释的范围**。

## 排除掉的三个解释

每一条都做了实验，不是推理：

| 假设 | 怎么验的 | 结果 |
|---|---|---|
| 截面朝向 n1 退化 | 逐个单元读 `.inp` 的 n1 | **否**。沿 X 的杆 n1=(0,0,1)，沿 Y 的杆 n1=(0,0,1)，都垂直于轴线 |
| 横向剪切刚度默认值 | 加 `*TRANSVERSE SHEAR STIFFNESS 1e12` 重跑 | **否**。Y 向响应仍是零 |
| 线性摄动步的影响 | 把 `*STEP, PERTURBATION` 换成普通静力步重跑 | **否**。结果一模一样 |

## 真正的原因：B31 是线性单元，而这里一根杆只划一个单元

把每根杆均分成 4 段、8 段重跑：

| 分量 | 本程序 | B31 (1 单元) | B31 (4 单元) | B31 (8 单元) |
|---|---|---|---|---|
| `u1` | 1.3314e-04 | 7.7189e-06 | 1.2334e-04 | **1.2903e-04** |
| `u2` | 1.4032e-05 | 1.8685e-19 | 1.3336e-05 | **1.3828e-05** |
| `ur1` | 3.7945e-03 | 0.0 | 3.5417e-03 | **3.7338e-03** |
| `rf2` | 4.8017e+03 | 1.1701e-13 | 4.5585e+03 | **4.7324e+03** |
| `u3` | 1.5204e-03 | 1.5078e-03 | 1.5200e-03 | **1.5206e-03** |

**单调收敛到本程序的值**，8 单元时差 1.5% ~ 3%。

道理是标准的：B31 用线性插值，单元内弯矩为常数，一根杆一个单元时表达不了
杆端转动主导的次生响应；B33 用三次插值，对端部受载的 Euler-Bernoulli 梁
一个单元就是精确解。竖向位移由分布荷载主导，所以 B31 勉强跟得上；
而水平位移与转角是由节点转动耦合出来的，粗网格下直接消失。

## 结论

- **B31 那组偏差的主因是离散误差，不是梁理论的格式差异。** 想拿 B31 当
  对照，必须先加密网格；一根杆一个单元的 B31 不构成有效对照。
- **本程序的解得到了印证**：B33（同格式、一个单元即精确）与加密后的 B31
  都收敛到同一组数值。
- `benchmark_B31.md` 与《课程报告》5.3 已按此更新。

## 怎么复现

```bat
python abaqus_bench\export_inp.py
abaqus_bench\run_abaqus.bat
python abaqus_bench\compare.py --element B31
```

加密那组是一次性实验，脚本没有入库——把每根杆均分成 n 段、荷载原样落到
每个子段上，再用 `inp_writer.write_inp(..., element="B31")` 导出即可。
