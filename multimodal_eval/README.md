# Multimodal evaluation corpus

`manifest.json` is the only release-gating input. The 30 images are original,
deterministic line drawings generated by `generate_seed_assets.py` and released
as CC0-1.0. They cover clear geometry, skewed/hand-drawn geometry, missing scale,
intersection ambiguity, blurred symbols, supports, loads, and photo-like noise.
Regenerate them only intentionally: changing any asset also changes its recorded
SHA-256 and should be reviewed as a corpus change.

Run the frozen offline gate with:

```text
python -m multimodal_eval.evaluate --output multimodal_eval/release_report.json
```

Every response fixture records redaction status plus provider/model/prompt/schema
fingerprints. The perfect fixture-replay score proves deterministic scoring and
release reproducibility; it is not a claim of live-provider accuracy.

`provider_smoke.py` tests at most one image per configured provider. Missing keys
are recorded as `SKIPPED_NO_CREDENTIALS`; these smoke results never enter the
offline score corpus.

## Real-world acceptance

Private real drawings use the separate `real_world_cases/` area and
`real_world_eval.py`; they never enter the synthetic fixture score. Run `init`,
complete consent metadata and independently verified ground truth, run
`recognize`, then `freeze` and `evaluate`. The freeze step rejects incomplete
cases and binds the image, annotation, and response hashes, so a later edit
cannot silently change a reported result. See `real_world_cases/README.md` for
the exact commands and privacy rules.
