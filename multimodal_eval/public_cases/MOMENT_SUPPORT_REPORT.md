# 圆弧中心与支座符号复核 — 2026-10-09

本轮处理前轮混合图力矩中心偏约 37 像素及支座按习惯误判的问题。作用点复核仍
默认关闭、每次额外一次视觉调用；同一阶段现在报告已有支座的可见三角、滚轮、
圆形或墙符号，不根据静定性或右端位置推断滚动。代码将符号转为未审核约束候选。

对于已观察为力矩的符号，代码在其附近找唯一彩色圆弧，确定性拟合圆心后投影到
所引用杆件。颜色只用于分离笔画，不决定其是否力矩、反力或外荷载。灰度、短弧、
多圆、远离杆件或不满足拟合条件时保留原模型观察；有人工审核或确认尺度也不改。
原位置、圆心、半径、拟合证据均保留，候选未知置信度，不能补荷载值或真实长度。

## 调用后发现的兼容问题与零调用修复

接受支座可选的有限 0..1 或 null 置信度元数据，不允许布尔、文字、非有限值或数值
约束字段，且不会把置信度变成人工确认。修复可选复核回放失败时丢弃有效基础草稿
的问题：保留基础预测、单独报告阶段失败，与桌面处理一致；缺少复核原文也不能
声称阶段完成。错误提示重复句号同步修正。

原[首次回放](action_review_02/replay_report.json)因该格式问题丢弃一张基础图，节点/
杆件 F1 为 0.800，原记录保留。[修复后回放](action_review_02/current_replay.json)
新增调用为 0，阶段完成 3/3，节点/杆件/支座 F1 为 1.000，荷载 F1 仍为 0、完整
验收仍失败。问题误报为 25，仍需减少重复审核提示；没有通过删除问题提高成绩。
调用后源码与回放另存快照，并绑定原在线/原回放哈希，不替换调用前版本。
前轮 action_review_01 的 0.889/0.667 在线几何成绩同样不重写，当前代码的像素回放
提升只能计为离线改进，原支座差异仍保留。

## 人工操作与限制

手工设置或删除支座保留原符号、约束和观察，只有精确绑定的支座符号复核问题被
处理；全局或混合问题继续审核。支座改名后其他问题引用随名称更新，仍能定位。
未知、错误节点、远离附着处或人工已审核支座不自动覆盖。

125% / 150% 原生窗口使用当前代码回放本轮原文，两图候选覆盖、设置复选框、
支座编辑按钮及 300% 预览滚动可用；没有人工拖点或输入荷载数值，导入仍阻断。
